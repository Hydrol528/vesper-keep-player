Jellyfin is on another computer, or uses a different address

Use this only when Jellyfin Server runs somewhere else. A laptop used just to approve the code does not need a different address.

On the computer with Jellyfin Server, open Jellyfin in a browser. Copy the address before /web. Both computers must be on the same home network for a local address to work.

For Windows: Settings → Network & internet → your connected Wi-Fi or Ethernet → Properties → IPv4 address. Use http:// followed by that address, then :8096 (the default port).

Allow Vesper Keep to open your library

Quick Connect is Jellyfin's way of asking your permission. You do this in Jellyfin, using the code below.

  1. Choose Open Jellyfin above. Jellyfin opens in a new browser tab.
  2. If Jellyfin asks you to sign in, use your Jellyfin username and password. These belong to the Jellyfin server you are connecting to; there is no separate Vesper account.
  3. Open the user/profile menu in Jellyfin (usually the person icon or profile picture near the top right). Choose Quick Connect. If the link already opened Quick Connect, skip this step.
  4. Paste the six-digit code shown above (or type it if copying was blocked) into Jellyfin's Quick Connect box. Choose Authorize or the confirmation button shown there.
  5. Return to this Vesper Keep tab. Your library opens automatically after approval. You do not need to type the code into VRChat.

Code expired? Choose Connect Jellyfin again here to get a fresh code. If Quick Connect is missing or disabled, ask the person who manages that Jellyfin server to enable it.

How to use the player — step by step
Where do I find my Jellyfin address?

Jellyfin Server must already be set up with a library. This address opens Jellyfin; it is not a movie folder.

  1. Jellyfin runs on this computer: enter http://localhost:8096.
  2. Jellyfin runs on another Windows computer: on that computer, open Settings → Network & internet → the connected Wi-Fi or Ethernet connection → Properties. Find IPv4 address. Enter http://THAT-IP:8096 here. For example, http://192.168.1.50:8096 is an example only. Both devices must be on the same home network.
  3. Already using Jellyfin in a browser: copy its address up to the port number, leaving off /web and anything after it.

These are the default addresses. If the server uses a custom port, HTTPS, or a remote address, use its configured address instead. Use only a server you own or have permission to access. Sign in to Jellyfin to approve the connection.

1. Connect Jellyfin

  1. For Jellyfin on the computer running this player, leave the default connection alone. For another computer, open the other-computer option and enter its Jellyfin address.
  2. Choose Connect Jellyfin.
  3. Keep the approval code visible and choose Open Jellyfin.
  4. In Jellyfin, open your user menu, then Quick Connect. Enter the code and confirm.
  5. Return to this page. It connects automatically after approval. If the code expires, request a new one.

Your password stays in Jellyfin. Keep your pairing link private.

2. Pair the in-world menu

  1. Choose Pair my in-world menu on this page and wait for your link.
  2. Open the Jellyfin tab in the player menu in VRChat.
  3. If the pairing field already contains an address ending in /p/, choose Copy code here and paste it after that address. If the field is empty, choose Copy full link instead.
  4. Choose Connect library in VRChat. Your catalogue appears after the connection completes. Pairing links expire after five minutes; create a new one when needed.

3. Browse and play

  1. Choose a category or use Search this view. Use Previous and Next to browse more titles.
  2. Select a movie poster. For a series, select the series, season, then episode.
  3. Choose Play on the details panel.
  4. Use the video player controls to pause, resume, change volume, or seek. Use Back to return to browsing.

4. Autoplay episodes

  1. Leave Autoplay following episodes checked if you want to continue the series.
  2. When the episode ends, the next available episode starts after the countdown.
  3. Uncheck autoplay or choose Cancel autoplay to prevent the next episode from starting.

5. Disconnect

  1. Choose Stop pairing on this page to disconnect the in-world menu while staying signed into Jellyfin. This does not stop the current video.
  2. Use the video player's Stop control to stop playback.
  3. Choose Disconnect Jellyfin to disconnect this page from Jellyfin. Create a fresh pairing when you return.

Troubleshooting

  • Approval code expired: choose Connect Jellyfin again and approve the new code.
  • Pairing unavailable: create a fresh pairing link and check that it was pasted only once, with no spaces.
  • Missing title or poster: check that it appears in your Jellyfin library.
  • Video does not start: read the player status and check VRChat's Allow Untrusted URLs setting. If it still fails, report the status message.
